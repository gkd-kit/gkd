# 模块职责

- 本模块仅用于提供可控的真机无障碍节点、事件及节点读取延迟，作为 GKD 无障碍测试的独立目标应用。
- 允许记录验证上述场景所需的触摸事件及状态，不引入 GKD 业务模块依赖。
- 测试编排、断言、构建安装、报告生成和清理逻辑留在根 `scripts/desktop`，不搬入本模块。
- 不添加业务逻辑、通用测试工具或与无障碍场景无关的功能。扩展模块职责前必须取得用户明确同意。
- 模块名为 `gkd-a11y-fixture`，Kotlin 包名、Android namespace 和 applicationId 统一为 `li.gkd.a11y.fixture`；源码放在 `src/main/kotlin` 对应包目录。
- 测试应用及测试数据不承担旧版本兼容；标识或模型变更时同步测试脚本和断言，不添加旧格式适配。
